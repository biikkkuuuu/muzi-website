# MUZI Music — Official Landing Website 🎵

> Unbox sound worth talking about. 100% Free, Open-Source & Lossless HD Music Streaming with Zero Ads.

## ✨ Features
- **3D Interactive Unboxing Experience**: Smooth scroll and 3D frame sequence animations.
- **Interactive Genre Discovery**: Hover-reactive floating album covers for Bollywood, Hip-Hop, Bhojpuri, Punjabi, and Haryanvi.
- **Cross-Platform Showcase**: Preview Android APK & PC Desktop Kotlin Multiplatform editions.
- **Curated Monthly Drops**: Discover trending releases and crate collections.

## 🚀 Live Demo & Repository
